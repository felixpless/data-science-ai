# 06 — Object-Oriented Programming

Use Order and Shipment instances to see how changing delivery status affects the results of method calls.

## Run the exercise

From this lesson folder, run `python3 oop_practice.py`. [Open the exercise](oop_practice.py).

An `Order` holds revenue, cost, and delivery status. Before delivery, profit is zero and margin is undefined. Mark the second order as delivered and compare its results. A zero-revenue order also has an undefined margin.

A `Shipment` holds distance, cost, and delivery status. Its cost per kilometre is cost divided by distance. A distance of zero yields `None`.
